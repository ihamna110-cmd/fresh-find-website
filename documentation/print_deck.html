Problem Definition & Market Friction

⚡

1. Schedule Fragmentation

Farmers markets operate on irregular, rotational schedules (e.g. 1st Saturday of the month, or Wednesday twilight hours). Citizens rely on scattered paper flyers and outdated social media pages, leading to wasted travel.

🚚

2. Food Miles Obscurity

Commercial supermarkets ship produce an average of 1,500 to 2,500 miles. Consumers have zero visibility into transit emissions, chemical wax preservatives, or nutritional depletion caused by extended cold storage.

📉

Middlemen and corporate logistics absorb up to 85% of retail produce prices. Local regenerative farms struggle to achieve direct-to-consumer discovery without costly advertising platforms.

💡

FreshFind solves this three-pronged dilemma through an open, browser-native intelligence hub. By evaluating live temporal schedules, mapping geographical vendors with zero API fees, and computing real carbon savings, FreshFind converts sporadic farmers market trips into convenient weekly habits.

Schedule Evaluation Logic
function evaluateMarketStatus(market, now = new Date()) {
  const currentDay = ['Sunday','Monday','Tuesday','Wednesday','Thursday','Friday','Saturday'][now.getDay()];
  if (!market.days.includes(currentDay)) return { status: 'CLOSED', next: getNextOpenDay(market) };
  
  const currentMins = now.getHours() * 60 + now.getMinutes();
  if (currentMins >= market.openMins && currentMins < market.closeMins - 45) return { status: 'OPEN' };
  if (currentMins >= market.closeMins - 45 && currentMins < market.closeMins) return { status: 'CLOSING_SOON' };
  return { status: 'CLOSED', next: getNextOpenDay(market) };
}

Haversine Distance & Proximity Geolocation

Spherical trigonometry calculation ordering regional farmers markets by user proximity
PAGE 16 / 42
Reading Time: 3 min
📐

Haversine Formula Implementation

When the user grants browser geolocation permissions (or inputs a city/zip), FreshFind calculates great-circle distance between coordinates on a sphere of radius R = 6,371 km:

const R = 6371; // Earth radius in km
const dLat = toRad(lat2 - lat1);
const dLon = toRad(lon2 - lon1);
const a = Math.sin(dLat/2)**2 + 
          Math.cos(toRad(lat1)) * Math.cos(toRad(lat2)) * 
          Math.sin(dLon/2)**2;
const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
const distance = (R * c).toFixed(1); // kilometers
⚡

Instant Proximity Sorting

All markets are dynamically re-ranked in ascending distance order. A distance badge (e.g. 📍 1.4 km away) renders on each market card, accompanied by an estimate of walking, cycling, or transit travel duration.

Supermarket produce travels an average of 2,400 km via refrigerated diesel freight (0.19 kg CO₂e per ton-km). Local farmers markets travel an average of 28 km.
